
# Core Java – OOPS Assessment

## Project Overview

This project contains 10 Java programming solutions developed as part of the Core Java OOPS Assessment.

The main objective of this project is to understand and implement Object-Oriented Programming (OOPS) concepts using Java.

Each question is implemented as a separate Java program using appropriate classes, objects, inheritance, abstraction, interfaces, and polymorphism.

## Technologies Used

- Programming Language: Java
- IDE: Visual Studio Code
- Version Control: Git and GitHub

## OOPS Concepts Covered

This project demonstrates the following Object-Oriented Programming concepts:

1. **Encapsulation** – Protecting data using private variables and getter methods.
2. **Inheritance** – Reusing properties and methods from parent classes.
3. **Polymorphism** – Using method overriding and parent-class references.
4. **Abstraction** – Hiding implementation details using abstract classes.
5. **Interfaces** – Defining common methods for different classes.
6. **Method Overloading** – Using the same method name with different parameters.
7. **Method Overriding** – Providing specific implementations in child classes.

## How to Run the Programs

### Step 1: Install Java

Make sure Java JDK is installed on your computer.

Check the Java version using:

```bash
java -version
```

Check the Java compiler using:

```bash
javac -version
```

### Step 2: Open the Project

1. Open Visual Studio Code.
2. Select File → Open Folder.
3. Choose the `Assesment_1` project folder.

### Step 3: Select a Question

Open any question folder.

For example:

```text
01-Employee-Salary/
```

### Step 4: Compile the Program

Open the terminal inside that folder and execute:

```bash
javac Main.java
```

### Step 5: Execute the Program

Run the compiled Java program:

```bash
java Main
```

### Step 6: Enter the Input

Provide the input according to the question's requirements and check the output in the terminal.

**Note:** Each question is an independent Java program. Run one question at a time from its respective folder.
